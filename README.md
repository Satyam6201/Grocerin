# 📖 About

GrocerinX is a production-ready **MERN Stack Grocery E-Commerce Application** built with scalability and clean architecture in mind.

The platform enables users to browse grocery products, manage carts, save multiple delivery addresses, place secure online orders using Stripe, and track purchases.

It also includes a powerful Seller Dashboard where admins can manage products, orders, inventory, and categories.

This project was developed to simulate a real-world grocery marketplace with modern technologies and industry-standard best practices.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/GrocerinX.git
```

---

## Install Frontend

```bash
cd client
npm install
```

---

## Install Backend

```bash
cd server
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5000

MONGO_URI=

JWT_SECRET=

STRIPE_SECRET_KEY=

STRIPE_WEBHOOK_SECRET=

CLIENT_URL=http://localhost:5173

CLOUDINARY_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_API_SECRET=
```
